Clean, modern single-page website for Esnad Lathe Workshop L.L.C.

## Features
- Responsive design (mobile, tablet, desktop)
- Hero image + About image + Gallery section
- Estimated stats: 8+ Years | 250+ Projects | 120+ Clients
- Contact form (front-end demo)
- Location: Al Sajaa, Sharjah, UAE
- Phone: +971 52 123 0823

## How to Open
1. Unzip the folder
2. Open `index.html` in any modern browser
   (or run a local server: `python3 -m http.server 8000`)
